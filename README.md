# ☕ Best Coffee

موقع كافيه عصري تم تطويره باستخدام **React.js**، ويهدف إلى تقديم تجربة بسيطة وجذابة لعرض الكافيه وقائمة المشروبات والخدمات.

## 🚀 تشغيل المشروع

بعد تحميل المشروع، افتح الـ Terminal داخل مجلد المشروع واكتب:

```bash
npm install
```

بعد تثبيت جميع المكتبات، شغّل المشروع:

```bash
npm start
```

ثم افتح الرابط الذي يظهر لك في المتصفح.
